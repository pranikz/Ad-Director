    Director

    Open a project to start. Director runs on your own Claude Code, with your plugins, skills and MCPs.
    Step 1 of 3

    Connect Claude Code

    Director runs on your own Claude Code: your login, plugins, skills and MCP servers. Nothing is sent anywhere else.

    Looking for Claude Code…
    npm install -g @anthropic-ai/claude-code
    Step 2 of 3

    Connect a media MCP

    Director generates plates and films through a media MCP server. Connect one or more; you can add others later in Settings.

    AI Studio MCPNot connected

    Galleri5 AI Studio's Model Garden: Seedance, Veo, Kling, Nano Banana and more. Runs locally with uvx and signs in with Google. Needs an AI Studio account.

    Higgsfield MCPNot connected

    Higgsfield's hosted server (Soul, Veo, Kling, Seedance and others). Added to your Claude Code, which handles the Higgsfield sign-in.

    claudethen type/mcpand pick higgsfield to sign in
    Another MCP server

    fal, Replicate, Runway, your own: any stdio or HTTP server in Claude Code's mcpServers format.

    Step 3 of 3

    Add Gemini for VLM checks optional

    A Gemini key lets you run a second-opinion video check on any take: dialogue timings plus a glitch report on the timeline. Claude Code reviews contact sheets on its own, so you can skip this.

    Settings

    Claude Code

    Director runs your own Claude Code: same login, plugins, skills and MCPs. The Director plugin is added to every chat.

    Checking…

    Media MCPs

    Servers here are passed to Director with --mcp-config. Servers already in your Claude Code (like Higgsfield after setup) load on their own. Add "enabled": false to keep one without loading it.

      Google Gemini optional

      For VLM checks on takes: dialogue timings plus a glitch report. Claude Code reviews contact sheets on its own, so this is a second opinion. The key is stored in your macOS keychain.
